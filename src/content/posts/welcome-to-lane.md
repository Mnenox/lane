Through a noisy street, past a stretch of neon signs, you arrive at this secret corner that can keep every kind of story. Post the things you love here, in this little alley!

## What's in lane

- **An entrance that always welcomes you!** Every time you open lane, you pass through neon lightboxes saying "hello" in twenty-plus languages. And if you ever grow tired of such enthusiastic greetings, a click or Esc skips them politely.
- **Posters you paste with your own hands!** Every blog post in lane becomes a 2:3 poster. May these neon-coloured posters make your stories a little more brilliant.
- **Words that cross borders!** lane matches your visitor's system language automatically. Love and beauty are never bound by language — and neither are the stories you keep here.

## Quick start

```bash
git clone <your-repo> lane && cd lane
npm install
npm run dev       # http://localhost:4321
npm run build     # static output in dist/
```

Set Pages to "GitHub Actions", push `main`, and you are live. To write, drop a Markdown file into `src/content/posts/` — or never touch a file at all, see below.

## The desktop lane

Zero code! Zero command line! A writing desk with live preview, an asset library that compresses to WebP for you, scheduled publishing, backup and restore… If lane is your first blog, you will get up to speed remarkably fast.
